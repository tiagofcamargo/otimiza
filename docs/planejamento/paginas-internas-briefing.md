# OTIMIZA — PRÓXIMA ETAPA

A Home está aprovada e finalizada.

Preserve integralmente a linguagem visual já estabelecida.

Não redesenhe:

* Header;
* Footer;
* tipografia;
* paleta;
* botões;
* cards;
* spacing system;
* linguagem de ilustração;
* comportamento mobile;
* design tokens.

A Home agora é a referência visual oficial do projeto.

Nesta etapa quero implementar SOMENTE:

1. página `/sobre`
2. página `/servicos`
3. página `/servicos/planejamento-tributario`

Não avance para os demais serviços ainda.

---

# 1. PRINCÍPIO GERAL

As páginas internas devem parecer parte do mesmo sistema visual da Home, mas NÃO devem ser cópias estruturais dela.

Cada tipo de página deve ter função própria:

## Sobre

Construir confiança institucional.

## Serviços

Ajudar o visitante a entender qual frente da Otimiza faz sentido para sua necessidade.

## Planejamento Tributário

Explicar profundamente o serviço, demonstrar conhecimento técnico e converter um visitante de alta intenção.

* filosofia de trabalho;

* responsabilidade;
* proximidade;
* clareza;
* segurança;
* compreensão do negócio do cliente.
